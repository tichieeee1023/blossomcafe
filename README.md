readme_content = """# ☕ Pink Blossom Café (핑크 블라썸 카페 쇼핑몰)

Vanilla HTML, CSS, JavaScript로 구현한 핑크 감성의 카페 콘셉트 쇼핑몰 프로젝트입니다. JSON 데이터를 이용한 상품 동적 게시, 실시간 날씨 및 시간 위젯, 카카오맵 API 연동, 그리고 4개의 독립된 서브 페이지 네비게이션을 포함하고 있습니다.

---

## 📅 프로젝트 개요
- **개발 기간**: 2026년 6월 2일 (1일 프로젝트)
- **사용 기술**: HTML5, CSS3, JavaScript (ES6)
- **테마 컬러**: 핑크(Pink) 계열 파스텔 톤 (`#FFB7B2`, `#FFC6FF`, `#FF85A2`)
- **디자인 콘셉트**: 아늑하고 사랑스러운 분위기의 디저트 & 음료 카페

---

## ✨ 핵심 기능

### 1. 🛍️ JSON 기반 상품 게시 (쇼핑몰 기능)
- `products.json`에 저장된 상품 데이터(메뉴명, 가격, 이미지 경로, 카테고리 등)를 JavaScript의 `fetch` API를 사용하여 동적으로 불러옵니다.
- 쇼핑 페이지에 그리드 레이아웃 형태로 상품 카드를 자동 렌더링합니다.

### 2. 🌤️ 실시간 날씨 및 일시 표시 위젯
- JavaScript `Date` 객체를 활용해 현재 날짜와 매초 흐르는 실시간 시간을 화면 상단에 표시합니다.
- Weather API(OpenWeatherMap 등)를 연동하여 오늘 현재 날씨 정보(온도, 날씨 아이콘 등)를 실시간으로 반영합니다.

### 3. 📍 카카오맵 API 연동 (오시는 길 안내)
- **Kakao 지도 API**를 사용하여 카페의 오프라인 위치를 보여주는 대화형 지도를 임베딩했습니다.
- 고유 마커 및 커스텀 오버레이를 통해 주소와 매장 정보를 직관적으로 안내합니다.

### 4. 🗺️ 상단 네비게이션 및 4개 서브 페이지 구성
- 상단 고정 네비게이션 바(GNB)에 세련된 호버 효과와 핑크 포인트 컬러를 적용했습니다.
- 각각 독립된 역할을 하는 **4개의 서브 메뉴/페이지**로 구성되어 있습니다.
  - **HOME (`index.html`)**: 브랜드 메인 비주얼 배너 및 베스트 상품/공지사항 소개
  - **ABOUT (`about.html`)**: 핑크 블라썸 카페의 브랜드 스토리 및 인테리어 콘셉트 소개
  - **SHOP (`shop.html`)**: JSON 데이터를 받아와 전체 메뉴 및 굿즈를 노출하는 쇼핑 페이지
  - **LOCATION (`location.html`)**: 카카오맵 API 기반의 오시는 길 및 매장 정보 페이지
